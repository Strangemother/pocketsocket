NOTES
==============================================================================
* Fairness: minimal echo handler on every server, no middleware, no
  access logging, same client, same host, run back to back.
* The asyncio servers run a single-threaded event loop. pocketsocket
  runs a dedicated io thread plus a worker pool, which costs a thread
  handoff per message but scales across cores. On a small host that
  handoff is visible; on a larger host it is what buys headroom.
* ps-nim-echo has no equivalent among the others: the message never
  enters Python at all.
